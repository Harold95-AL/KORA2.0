# Paquete visual del bosque pantanoso

El nivel **2.3 — El guardián del bosque** puede usar localmente el paquete
Fantasy Swamp Forest de **The Flavare**. La escena carga sus fondos, parallax
y decoración desde la subcarpeta `Free` ubicada en:

`assets/external/forest-nature-fantasy-tileset-free/Fantasy Swamp Forest/Free/`

Si se clona este proyecto sin el paquete, el nivel sigue abriendo con su
blockout y la escena omite esas capas visuales. Para activarlas localmente,
obtén el paquete desde el autor y conserva su estructura de carpetas y archivos.

El paquete Free permite usar los recursos dentro de juegos y otros proyectos,
pero prohíbe modificar, revender o redistribuir el paquete. Por eso la carpeta
de arte está excluida de Git; este repositorio conserva únicamente el código de
integración y esta referencia. No se han alterado los PNG originales.

Crédito: **The Flavare — Fantasy Swamp Forest**. La licencia y el README
originales se conservan junto con la copia local del paquete.
